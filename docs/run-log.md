### 외부 원고 점검: 시연 원고(stage2/measurements.md 2.5절) 1회

카드는 2회차 카드 재사용. 원고 문장 근거 연결은 캐시, 교차 판정 Claude Opus 5.5(로컬 CLI), 고쳐 쓴 제안 DeepSeek.

- 총 점검 시간(서버 측정): 66.0초(교차 판정 34.8초, 고쳐 쓴 제안 31.2초)
- 문장 11개, 근거 연결 9/11(81.8%), 사실 문장 7개 모두 카드 연결
- 틀린 문장 3개 경고: 3/3 (코드 판정 기준)
  - "녹취 성공률이 100%…": 코드 '근거 없음'(연결 카드에 100% 근거 없음) + 모델 '근거 없음'
  - "PC폰만 설치하면 모든 통화가 PC에 저장": 코드 '사양 불일치'(단정 표현 + 조건 있는 카드) + 모델 '사양 불일치'
  - "전국 학교 300곳…": 코드 '수치 충돌'(근거 원문 200여개/150+와 다름) + 모델 '근거 없음'
- 가이드라인 누락(코드): 필수 키워드 '업무자동화'(제목·본문), 상담 문의 정보(1877-3836·center.php) — 원고에 넣은 두 누락이 모두 잡힘
- 강조 내용 11개(모델 판정): 11개 모두 '반영되지 않음'
- 오경고: 모델이 바른 문장 3개(AI 요약 문장, AES256 문장, 종합리포트 문장)를 '근거 없음'으로 판정 → 판정 엇갈림 3건(코드 통과/모델 경고)
