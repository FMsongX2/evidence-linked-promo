- E05: 코드 수치 대조가 같은 제품명(TlinkPhone)이 든 설치 단계 번호 줄을 같은 맥락으로 보고 "'60개 이상'이 원문 '4'와 다르다"는 틀린 설명을 냈다. 짧은 줄의 낱말 겹침만으로 같은 지표로 보는 규칙의 한계다. 경고 자체는 다른 경고(단정 표현)로 맞게 떴다.
